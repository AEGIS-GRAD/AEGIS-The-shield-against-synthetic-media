AEGIS is an agentic, edge-optimized, explainable deepfake verification system. The system consists of three main layers: an orchestration agent, a hardware-aware inference engine, and a multi-agent debate/explainability layer. This repository is organized as a monorepo, where each main component resides in its own dedicated folder. This structure allows for independent development, testing, and deployment of the microservices while maintaining a cohesive overall architecture.
